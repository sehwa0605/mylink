# mylink (마이링크)

> 양세화의 프로필과 링크를 한곳에 모아 공유하는 링크인바이오 서비스

## 소개
내 프로필과 여러 링크를 한 페이지에 모아 공유할 수 있는 나만의 웹 서비스입니다.

## 기술 스택
- **프레임워크:** Next.js 16.3.4 (App Router)
- **라이브러리:** React 19
- **언어:** TypeScript 5
- **스타일링:** Tailwind CSS v4

## 시작하기

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속하여 확인할 수 있습니다.
